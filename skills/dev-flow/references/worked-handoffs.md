# Handoff examples

## A delegated integration

For artifact acquisition, identify the real caller, who supplies the input identity, who consumes the returned path and who releases it. Assign the shared integration point when delegating. Verify acquisition through that caller. If upstream data is missing, keep the integration check open and continue the independent work.

## Resuming two outcomes on one change

Suppose the accepted change updates a column heading in both browser and nightly exports. The record for candidate `r18` links the downloaded browser file to `WEB-1`. Its first row matches the agreed heading. `JOB-2` has a passing formatter unit test from `r17`, but the nightly entry still calls its legacy exporter. Keep the browser evidence. The outstanding work is to connect the nightly consumer and compare a file produced by that job with the required heading. Record who can run that check and on which candidate. It stays pending until the artifact exists.

## A small correction

To correct a misspelled settings label, find the label and its localization or callers, make the text change and run the relevant label check. A short note with the changed text and the result is sufficient.
